How this plus-size starting point is calculated

This calculator uses the same core measurement relationship as the main bra calculator rather than applying a separate plus-size correction formula.

  1. Band: the snug underbust determines the even-number band reference.
  2. Cup: standing bust minus snug underbust determines the cup index.
  3. Optional measurements: loose, tight, and leaning measurements provide additional fit context but do not get blended into the cup calculation.
  4. Labels: the same cup index is mapped into the US and UK sequences.

Plus-size garments can use different constructions, proportions, support features, and size ranges. Compare the starting point with the manufacturer's current chart and the actual garment fit.
