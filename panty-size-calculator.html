How the panty size is calculated

The calculator compares your waist and hip measurements with the site's panty reference table. It does not assume that one measurement is always more important for every garment.

  1. Measure: enter your natural waist and fullest hip measurements.
  2. Reference match: the calculator first looks for a row that accommodates both measurements.
  3. Fallback: if no row contains both measurements, the hip measurement is used to find the closest available reference row.
  4. Conversion: the selected row supplies the alpha, US, UK, and EU labels shown in the result.

Rise, fabric stretch, garment construction, and manufacturer sizing can change the appropriate size. Use the result as a reference and check the product's own chart.
