# BraSizePRO: Free Bra Size Calculators and Fit Guides

Free online bra size calculators, size converters, and plain-language fit guides. Enter your measurements, get a **starting size**, compare US, UK, EU and AU labels, and learn how to check the fit in a real garment.

**Try it online: [brasizepro.com](https://brasizepro.com)**

BraSizePRO gives measurement-based starting points, not guarantees. Brand charts, cup shape and construction all change how a bra fits, so every tool points you back to the garment's own size chart.

## Calculators and tools

### Bra sizing

#### [Universal Bra Size Calculator](https://brasizepro.com/bra-size-calculator)
Enter your snug underbust and standing bust measurements to get a starting bra size, shown in US, UK, EU and AU labels. It also lists the two nearest sister sizes, one with a snugger band and one with a looser band. Tight underbust and leaning bust are optional and don't change the result.

#### [Sister Size Calculator](https://brasizepro.com/sister-size-calculator)
Pick your current band and cup and see the neighbouring band-and-cup combinations (for example, a smaller band with a bigger cup). Useful when a bra almost fits but the band feels too loose or too tight.

#### [Brand Size Converter](https://brasizepro.com/brand-size-converter)
Enter a baseline size and compare how it maps to the size labels of selected brands, including Panache, Freya, Wacoal, Victoria's Secret, Natori, ThirdLove, Aerie, Skims, Elomi and Curvy Kate. It is a label comparison only, so check each brand's current product chart before ordering.

#### [Bra Size to Measurements](https://brasizepro.com/bra-size-to-measurements)
The reverse of the calculator. Choose a bra size such as 34D and see the underbust and bust ranges it roughly corresponds to (about 33–35 in underbust for a 34D). Handy if you know your size and want to understand it.

#### [Bra Fit Checker](https://brasizepro.com/bra-fit-checker)
Choose the problem you notice (band riding up, straps digging, cups gaping, spillage, wires poking and so on) and get possible causes and adjustments to try. It doesn't diagnose a problem or promise an exact size.

### Specialty bras

#### [Sports Bra Calculator](https://brasizepro.com/sports-bra-calculator)
Estimates a sports bra starting size and gives support guidance for low, medium and high-impact activity. The activity level changes the style advice, not the size label.

#### [Strapless Bra Size Calculator](https://brasizepro.com/strapless-bra-size-calculator)
Gives a starting size for strapless bras and a checklist of what matters most without straps: band security, cup shape, wings and grip. It doesn't automatically recommend sizing down.

#### [Maternity & Nursing Bra Calculator](https://brasizepro.com/maternity-nursing-bra-calculator)
Estimates a starting size from current measurements, with fit guidance for each stage from the first trimester to postpartum. Measurements can change during pregnancy, so it treats the result as a snapshot to re-check.

#### [Plus-Size Bra Calculator](https://brasizepro.com/plus-size-bra-calculator)
A starting point for fuller band and cup sizes, shown in US and UK cup labels. It uses the same core method as the main calculator and accepts optional loose, tight and leaning measurements for extra context.

#### [Men's Bra Calculator](https://brasizepro.com/mens-bra-calculator)
Measurement-based sizing for men and gender-diverse shoppers, using underbust and chest measurements plus a torso-frame option for style guidance.

#### [First Bra Calculator](https://brasizepro.com/first-bra-calculator)
A gentle, no-pressure calculator for young people choosing a first training bra, camisole or starter bralette, with an emphasis on comfort.

### Panties, swimwear and shapewear

#### [Panty Size Calculator](https://brasizepro.com/panty-size-calculator)
Enter waist and hip measurements to get a panty size in alpha, US, UK and EU labels.

#### [Matching Set Calculator](https://brasizepro.com/matching-set-calculator)
Works out bra and bottom sizes separately from your underbust, bust and hips, so you can see when a fixed S/M/L set won't suit both measurements.

#### [Swimwear Size Calculator](https://brasizepro.com/swimwear-size-calculator)
Starting size for bra-sized bikinis and tankinis, plus notes on one-piece fit using a shoulder-to-crotch torso measurement.

#### [Shapewear Size Calculator](https://brasizepro.com/shapewear-size-calculator)
Estimates a shapewear starting size from waist and hips. The compression level changes the guidance, not the size, and it explains why sizing down for more compression isn't a good rule.

## How the sizing works

The calculators use one simple, repeatable method:

1. **Band:** the snug underbust measurement, rounded to the nearest even band number.
2. **Cup:** bust minus underbust, rounded to a whole number of inches, mapped to a cup letter in the chosen system.
3. **Labels:** the same result shown as US, UK, EU and AU sizes.

For example, a 32-inch underbust and a 36-inch bust give a 4-inch difference, which is a **32D** starting size.

This is a starting point, not a verdict. Research comparing measurement-based sizing with professional fitting has found differences between the two, so always check the actual bra and the brand's own size chart.
